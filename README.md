# WisePlate – Smart Meal Planner & Budget Guardian

Your personal Android app that helps yopu plan delicious meals and keeps your grocery budget under control.

Built with Kotlin + Jetpack Compose — modern, fast, and beautiful.

---

## Features

- Live Dashboard: See this week’s meals and monthly budget progress ring
- Drag-and-drop Meal Planner: 7-day calendar with breakfast, lunch, and dinner slots
- Smart Recipes: Built-in recipes with exact cost per serving
- Real-time Budget Tracking: Spending updates instantly as you plan meals
- Auto-Generated Shopping List: Grouped by aisle, with check-off items and running total
- Beautiful Material 3 Design: Clean green/orange theme
- Notifications and Alerts: Budget warning reminders
- Offline-first: All data saved locally
